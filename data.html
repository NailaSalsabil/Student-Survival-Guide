03 — CARI DATA

Butuh data?
Jangan asal download.

Pilih sumber data berdasarkan kebutuhan dan selalu periksa tahun, satuan, definisi, serta sumber datanya.

Data untuk tugas kuliah

Sumber data yang tepat membuat analisis menjadi lebih dapat dipertanggungjawabkan. Gunakan sumber resmi ketika tersedia.

SUMBER 01

Badan Pusat Statistik

Cocok untuk mencari data penduduk, kemiskinan, pendidikan, ketenagakerjaan, ekonomi, pertanian, sosial, dan berbagai statistik resmi Indonesia.

Cara mencari

  1. Masukkan kata kunci data.
  2. Pilih tabel atau publikasi yang sesuai.
  3. Periksa tahun data.
  4. Periksa satuan dan definisi variabel.
  5. Download data sesuai kebutuhan.
BPS
Buka BPS

SUMBER 02

Bank Indonesia

Cocok untuk data dan indikator ekonomi, keuangan, pasar uang, pasar modal, sistem pembayaran, dan indikator ekonomi lainnya.

Cocok digunakan untuk

  • Data ekonomi.
  • Data keuangan.
  • Indikator moneter.
  • Data pasar keuangan.
BI
Buka Bank Indonesia

SUMBER 03

World Bank Open Data

Dapat digunakan ketika membutuhkan data pembangunan dan indikator internasional untuk berbagai negara.

Contoh data

  • Population
  • GDP
  • Poverty
  • Education
  • Health
WB
Buka World Bank

SUMBER 04

Kaggle Datasets

Cocok untuk latihan analisis data, eksplorasi, visualisasi, dan pembelajaran.

Perhatian: Dataset Kaggle tidak otomatis merupakan data resmi. Periksa deskripsi dataset, sumber asli, tahun, variabel, satuan, dan lisensinya.
K
Buka Kaggle

SUMBER 05

Kementerian Kesehatan RI

Cocok untuk mencari data dan informasi terkait kesehatan masyarakat, fasilitas kesehatan, tenaga kesehatan, penyakit, pelayanan kesehatan, dan indikator kesehatan.

Cocok digunakan untuk

  • Data kesehatan masyarakat.
  • Data penyakit dan kondisi kesehatan.
  • Data fasilitas pelayanan kesehatan.
  • Data tenaga kesehatan.
  • Indikator kesehatan Indonesia.
